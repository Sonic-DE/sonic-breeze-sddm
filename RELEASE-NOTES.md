# Sonic Breeze SDDM Release Notes

Sonic Breeze SDDM brings the classic Breeze look to the SonicDE login screen.

## 6.8.2 (2026-11-10)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.

## 6.8.0 (2026-10-20)

- Behind the scenes: version update.

## 6.7.5 (2026-09-08)

- The Breeze login screen now uses modern built-in visual effects for its shadows, so it no longer needs older compatibility libraries installed.

## 6.7.4 (2026-08-29)

- The classic Breeze login screen theme is now available as its own package for SonicDE.
