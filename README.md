# sonic-breeze-sddm

The Breeze SDDM theme, moved from `sonic-desktop-interface` after it stopped
shipping an SDDM theme. CMake installs it as
`share/sddm/themes/breeze`.

The theme uses the shared `org.kde.breeze.components` QML module supplied by
`sonic-workspace`; this repository does not duplicate or rebuild that module.
